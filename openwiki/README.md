# Generated repository map

This directory is generated by [OpenWiki](https://github.com/langchain-ai/openwiki). It is advisory
navigation for coding agents — use it to locate code, trace dependencies, and identify likely files
for a task. It does not override `CLAUDE.md`, `AGENT.md`, or canonical architecture/compliance docs.

1. `CLAUDE.md` — hard invariants and behavioral rules
2. `AGENT.md` — repo briefing
3. `docs/` — canonical architecture, compliance, plans (`docs/00_architecture_plans_index.md`,
   `docs/roles/00_roles_index.md`)
4. `openwiki/` — this generated navigation layer

architecture, the document and assistant pipelines, the frontend, and the CI gates. Unlike this

`CLAUDE.md`/`AGENT.md`.

## Generating / updating

Requires an LLM API key (OpenWiki runs a DeepAgents documentation agent), so run locally:

```bash
npm install -g openwiki
openwiki --init      # first generation
openwiki --update    # refresh after code changes
```

## Review before committing generated output

OpenWiki may also create/append to `AGENTS.md` and `CLAUDE.md`. Inspect the full diff:

```bash
git diff -- CLAUDE.md AGENT.md AGENTS.md openwiki/
```

Reject or fix any generated text that weakens, contradicts, or restates less strictly the hard
invariants in `CLAUDE.md`: local-first (no network calls in product code), per-profile SQLCipher
isolation, redaction before export/external runners, audit logging, no medical advice,
ModelRunner-only LLM calls, dual Alembic migration chains.

## CI

Deferred. Do not add OpenWiki's GitHub Actions auto-update workflow until at least one manual
`openwiki --init` / `--update` cycle has been generated, reviewed, and merged. When added, it must
open PRs only — never auto-merge — because generated doc changes in this repo need human review.
