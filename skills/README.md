# `skills/` — Asclexis Project Skills

These are project-domain skills specific to Asclexis (backend conventions, guardrails, evals,
agent behavior) — see each subdirectory's `SKILL.md`. They are referenced from
[`docs/roles/`](../docs/roles/00_roles_index.md), particularly
[`ai-llm-pipeline-and-safety.md`](../docs/roles/ai-llm-pipeline-and-safety.md) and
[`backend-api.md`](../docs/roles/backend-api.md).

**Not to be confused with `.claude/skills/`**, which holds two vendored collections of
general-purpose Claude Code process skills: [Superpowers](https://github.com/obra/superpowers)
(14 skills, MIT: brainstorming, TDD, writing plans, etc.) and
[mattpocock/skills](https://github.com/mattpocock/skills) (18 skills, MIT), unrelated to this
project's own domain. See [`.claude/skills/README.md`](../.claude/skills/README.md).
