## Key Features

- **Document Import**: Upload lab results (PDF/images) for automatic extraction
- **Observation Tracking**: View, verify, and trend your lab values over time
- **AI Interpretations**: Get plain-language explanations of your results
- **Medication Management**: Track medications, schedules, and adherence
- **Export**: Generate clinician-ready summaries for doctor visits
- **Privacy First**: All data encrypted locally on your device
